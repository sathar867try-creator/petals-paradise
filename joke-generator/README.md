# Random Joke Generator 😂\n\nA fun and interactive web application that generates random jokes using the JokeAPI. Built with HTML, CSS, and vanilla JavaScript.\n\n## 🎯 Features\n\n✨ **Random Joke Generator** - Get unlimited jokes on demand\n🎭 **Multiple Categories** - All, General, Programming, Knock-Knock jokes\n⚡ **Instant Loading** - Fast API integration with loading states\n📋 **Copy & Share** - Easily copy jokes or share with friends\n❤️ **Favorites** - Save your favorite jokes locally\n📊 **Stats** - Track jokes loaded and favorites count\n📱 **Fully Responsive** - Works perfectly on desktop, tablet, and mobile\n🎨 **Modern UI** - Beautiful gradient design with smooth animations\n⌨️ **Keyboard Support** - Use buttons or keyboard shortcuts\n\n## 🚀 Live Demo\n\nhttps://sathar867try-creator.github.io/petals-paradise/joke-generator/\n\n## 📦 Technologies Used\n\n- **HTML5** - Semantic markup\n- **CSS3** - Modern styling with gradients and animations\n- **Vanilla JavaScript** - No frameworks, pure JS\n- **JokeAPI v2** - External API for joke data\n- **LocalStorage** - Browser storage for favorites\n- **Font Awesome** - Icons\n- **Google Fonts** - Poppins & Fredoka typography\n\n## 🎨 API Used\n\n[JokeAPI v2](https://jokeapi.dev/) - Free Joke API\n\n- **Endpoint:** `https://v2.jokeapi.dev/joke/{category}`\n- **Categories:** Any, General, Knock-Knock, Programming, Misc, Dark, Pun, Spooky, Christmas\n- **Rate Limit:** No limit\n- **Response Format:** JSON\n\n## 📂 Project Structure\n\n```\njoke-generator/\n├── index.html          # Main HTML file\n├── style.css           # CSS styling\n├── script.js           # JavaScript functionality\n└── README.md           # This file\n```\n\n## 💻 How to Use\n\n1. **Open the application**\n   - Visit: https://sathar867try-creator.github.io/petals-paradise/joke-generator/\n   - Or open `index.html` in your browser\n\n2. **Get a Joke**\n   - Click the \"Get Joke\" button\n   - A random joke will be displayed\n   - Wait for the animation and enjoy!\n\n3. **Filter by Category**\n   - Click on category buttons (All, General, Programming, Knock-Knock)\n   - Get jokes from that specific category\n\n4. **Save Favorites**\n   - Click the \"Favorite\" button to save a joke\n   - View all favorites in the \"Your Favorites\" section\n   - Favorites are saved in your browser\n\n5. **Share Jokes**\n   - Click \"Share\" to share with friends\n   - Click \"Copy\" to copy the joke text\n   - Use browser's share dialog (if available)\n\n## 🔧 Features Explained\n\n### Get Joke\n- Fetches a random joke from JokeAPI\n- Shows loading animation\n- Displays joke with category and type\n- Updates joke counter\n\n### Categories\n- **All** - Mix of all joke types\n- **General** - Clean, family-friendly jokes\n- **Programming** - Tech and programmer jokes\n- **Knock-Knock** - Classic knock-knock format\n\n### Favorites System\n- Save jokes to local storage\n- Persists across browser sessions\n- View all saved jokes in one place\n- Remove individual favorites\n- Counter shows total favorites\n\n### Share & Copy\n- **Copy** - Copies joke to clipboard\n- **Share** - Uses device share API or copies to clipboard\n- Supports modern browsers\n\n## 📊 Statistics\n\n- **Jokes Loaded** - Total jokes fetched\n- **Favorites** - Total saved favorites\n- Auto-updates as you interact\n\n## 🎯 Keyboard Shortcuts\n\nThe app supports keyboard interaction:\n- Tab to navigate buttons\n- Enter to click buttons\n- Escape to close notifications\n\n## 🌐 Browser Support\n\n✅ Chrome/Edge (latest)\n✅ Firefox (latest)\n✅ Safari (latest)\n✅ Mobile browsers\n✅ IE 11+ (with polyfills)\n\n## 📱 Responsive Design\n\n- **Desktop** (1200px+) -
