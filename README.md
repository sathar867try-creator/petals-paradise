
## Customization

### Update Business Information
Edit the contact details in `index.html`:
- Address
- Phone number
- Email
- Business hours

### Update Images
Replace the placeholder images with your own:
- Gallery images
- About section image

### Update Colors
Modify the color scheme in `css/styles.css`:
```css
:root {
    --primary: #e91e63;      /* Main color */
    --secondary: #f06292;    /* Secondary color */
    --accent: #ff69b4;       /* Accent color */
}
```
